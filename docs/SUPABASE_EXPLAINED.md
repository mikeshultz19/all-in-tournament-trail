# Supabase Explained

> Current-state note (2026-07-29): Supabase currently stores tournament,
> registration, Results, AOY-row, season, member, team, and reset foundations.
> Sponsor management and Championship qualification are not completed systems.

Version: 1.0
Last Updated: July 27, 2026

Supabase is the central database for AITT.

It stores:
- Tournaments
- Registrations
- Published Results
- AOY data
- Announcements
- Conditions
- Sponsors
- Winner Photos

The Admin Center writes data to Supabase.
The Public Website reads data from Supabase.
